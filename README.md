# 📚 Ejemplos de PHP - Curso de Programación

Este repositorio contiene ejemplos prácticos y ejercicios resueltos en **PHP** utilizados en el contexto del *Curso de Programación*.

> 💡 **Objetivo**: Reforzar los conceptos teóricos con ejemplos reales, desde fundamentos hasta características avanzadas del lenguaje.

---

## 📖 Contenido

Los ejemplos están organizados por temas o módulos:

| Módulo | Descripción | Enlace |
| -------- | ------------- | -------- |
| 🧱 Fundamentos | Variables, tipos de datos, operadores, estructuras condicionales y bucles | [`01-fundamentos/`](./01-fundamentos/) |
| 📦 Funciones y arrays | Definición de funciones, parámetros, arrays asociativos y multidimensionales | [`02-funciones-arrays/`](./02-funciones-arrays/) |
| 🌐 Formularios y HTTP | Manejo de `GET`, `POST`, validación y procesamiento de formularios | [`03-formularios/`](./03-formularios/) |
| 🗄️ Bases de datos (MySQLi/PDO) | Conexión, consultas, inserciones, actualizaciones y eliminaciones | [`04-bbdd/`](./04-bbdd/) |
| 🧩 POO en PHP | Clases, objetos, encapsulamiento, herencia y polimorfismo | [`05-poo/`](./05-poo/) |
| 🔐 Seguridad básica | Prevención de inyecciones SQL, XSS y validación segura | [`06-seguridad/`](./06-seguridad/) |

*(Los nombres de carpetas y contenido pueden variar según la estructura del curso)*

---

## 🛠️ Requisitos

- **PHP 8.1+** (recomendado)  
  Verifica tu versión con:

  ```bash
  php -v
  ```

- Servidor web (opcional, si trabajas con scripts que usan formularios o rutas HTTP)
- Editor de código (VS Code, PHPStorm, etc.)

---

## 📌 Notas

- Todos los ejemplos están probados y funcionan en entornos estándar.
- Se prioriza el uso de buenas prácticas: *PSR-12*, nombres descriptivos, comentarios útiles y manejo básico de errores.
- Los ejemplos con base de datos incluyen un archivo `schema.sql` para recrear la estructura.
